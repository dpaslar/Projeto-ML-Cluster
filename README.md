# Análise de Padrões de Consumo com K-Means
  Introdução
  Este projeto visa entender padrões de consumo de clientes com idades entre 18 e 70 anos e renda anual variando de R$ 20.000 a R$ 250.000. A análise utiliza técnicas de Machine Learning   para segmentar os clientes em grupos com comportamentos similares, auxiliando na tomada de decisão para marketing, personalização de produtos e estratégias de negócio.

## Objetivos
  Explorar dados de idade e renda anual dos clientes.

  Identificar segmentos de clientes (clusters) para entender comportamentos distintos.

  Visualizar a distribuição de clientes por cluster.

  Avaliar a consistência e separação entre os clusters identificados.

## Metodologia
  O projeto segue um fluxo de análise estruturado:

  Coleta e Limpeza de Dados – Preparação do dataset com apenas as colunas de interesse.

  Normalização – Padronização das variáveis para garantir comparabilidade entre características diferentes.

  Segmentação de Clientes – Aplicação do algoritmo de K-Means para agrupar clientes em clusters distintos.

  Avaliação e Visualização – Análise dos clusters gerados, visualizando padrões de consumo por idade e renda.

  Insights de Negócio – Extração de conclusões sobre comportamento do cliente para orientar estratégias de marketing e vendas.

## Resultados
  Os clientes foram segmentados em 4 clusters distintos, cada um com perfis únicos de idade e renda.

  A análise revelou padrões de consumo claros que podem orientar campanhas direcionadas.

  O modelo apresentou boa separação entre os clusters, indicando confiabilidade na segmentação.

## Aplicações e Insights
  Marketing Personalizado: Direcionamento de campanhas com base no perfil de cada cluster.

  Planejamento de Produto: Ajuste de ofertas e promoções de acordo com o comportamento dos clientes.

  Tomada de Decisão Estratégica: Identificação de grupos de alto valor e tendências de consumo.

## Possíveis Melhorias
  Incluir variáveis adicionais, como gênero, hábitos de consumo ou localização.

  Testar outros algoritmos de clusterização, como Hierarchical Clustering ou DBSCAN.
